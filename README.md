# prompt-pad

> Shows a Svelte overlay on every web page you visit, with an options page that moves it from right to left.

## Commands

### dev

Run the extension in development mode. Target a browser with `--browser`:

```bash
pnpm run dev
pnpm run dev -- --browser=firefox
pnpm run dev -- --browser=edge
```

### build

Build for production. Convenience scripts target each browser:

```bash
pnpm run build           # Chromium (default)
pnpm run build:firefox
pnpm run build:edge
```

### preview

Preview the production build in the browser:

```bash
pnpm run preview
```
